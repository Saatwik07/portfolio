# Saatwik Vaish | Portfolio

My personal portfolio website, built with pure HTML and CSS (no JavaScript). It showcases my skills, projects, and education as a B.Sc A.I. and Computer Science student at Scaler School of Technology.

**Live site:** https://saatwik07.github.io/portfolio/


## Features

- Dark theme with an animated gradient hero and floating background orbs
- Typing effect and orbiting planet animation, all in CSS
- Auto-scrolling logo marquees for skills (pause on hover)
- Responsive layout using Flexbox and Grid
- Project cards with live demos and GitHub links
- Semantic HTML with accessibility in mind

## Built with

- HTML5
- CSS3 (Flexbox, Grid, custom properties, keyframe animations, transitions)
- [Google Fonts](https://fonts.google.com/): Space Grotesk, JetBrains Mono
- [Devicon](https://devicon.dev/) for technology logos

## Run locally

```bash
git clone https://github.com/Saatwik07/portfolio.git
cd portfolio
```

Then open `index.html` in your browser. No build step or dependencies needed.
